# munin

Claude Code と Codex のすべての会話を1つの記憶にして、メッセージを送るたびに、関係する過去を思い出して Claude に渡す。
人の記憶のしくみ(意味ネットワーク・海馬・睡眠・想起による強化・忘却)を、そのままプログラムにしている。LLM は使わない。

名前は、北欧神話で主神オーディンに仕えるカラス「ムニン(Muninn、記憶)」から。
ムニンは毎日世界中を飛び回り、見てきたことをオーディンに伝える。

## 何をするか

```
<思い出したこと>
未完了のこと(期限・保留・連絡):
- [dc7e77fb-1] 10/21まで 「kintone環境準備の前倒し(10/21までに確定)」
関係しそうな記憶(確かさ順):
- [8351eb2f] 10/08 09:05 C:\dev\munin 「ネットワーク図出来てない。…」 確かさ0.86
  手がかり: ネットワーク図, タイル, 濃淡 / 返答「原因は、タイルの背景が透明だったことでした。…」
関係しそうな場所: C:\dev\munin
([ ] は記録の鍵。詳しい中身は python memory_detail.py 鍵 で開ける)
</思い出したこと>
```

中身を全部は渡さず、思い出す手がかりと、記録を開くための鍵だけを渡す。Claude は必要なら自分で記録を開く。

## しくみ

| 段階 | 人の記憶 | このプログラム |
|---|---|---|
| 覚える | 体験を海馬に一度で記録する | 1回の依頼とその後の作業を1つの出来事にし、語・ファイル・場所(概念)と依頼の意味(埋め込み)を記録する。全文は別に保存し、記憶は鍵だけを持つ(海馬インデックス理論) |
| 眠る | 睡眠中に海馬の記憶を再生し、皮質に定着させる | 日付が変わるたびに、最近の出来事を再生して概念どうしのつながりを強め、全体を少し弱め、弱いつながりは消える |
| 思い出す | 手がかりから連想が広がり、断片から再構成する | 依頼の語と作業フォルダを手がかりに活性を広げ(ACT-R の拡散活性化)、出来事を並べ、関係している確率(確信度)を付ける |
| 強化と忘却 | 思い出すほど思い出しやすく、使わないと思い出しにくい | ACT-R の基本活性化の式 |
| 展望記憶 | 「あとで〜する」を覚えておく | 「〜日までに」「保留」「〜さんに確認」を覚え、終わったら完了にする |
| ワーキングメモリ | 「これ」「直して」は今の話題を指す | 指示語や対象の省略があれば、直前の話題(5つまで)に注意を向ける |

## 必要なもの

- Python 3.10 以上: `pip install janome wordfreq numpy Pillow`
- [Ollama](https://ollama.com) と埋め込みモデル: `ollama pull qwen3-embedding:8b` と `ollama pull qwen3-embedding:0.6b`

## 使い方

```bash
python import_sessions.py      # すべてのセッション記録から記憶を作る(最初の1回)
python server.py               # 記憶を画面で見る(http://127.0.0.1:8770、ネットワーク図つき)
```

Claude Code につなぐには、`~/.claude/settings.json` の `hooks` に登録する。

```json
"UserPromptSubmit": [{"hooks": [{"type": "command", "command": "python C:/dev/munin/hook.py", "timeout": 15}]}],
"Stop": [{"hooks": [{"type": "command", "command": "python C:/dev/munin/hook.py --learn", "timeout": 10}]}]
```

- パスは `/` で区切る。Windows でもフックは bash で実行され、`\` が消えてファイルが見つからなくなる
  (Python は終了コード 2 で終わり、Claude Code はそれを「プロンプトを止める」と受け取る)
- メッセージを送るたびに思い出して差し込み、返答が終わるたびにそのやり取りを覚える。
  Codex の会話などは、1時間ごとに拾い直す。記憶は常駐サーバーが持ち、動いていなければフックが起動する

## 評価

```bash
python evaluate_memory.py                  # 調整用の期間で評価する
python evaluate_memory.py --mode test      # 最終確認用の期間で評価する(調整が終わったときだけ)
python compare_runs.py valid valid_sleep   # 同じ問題どうしで比べ、差が偶然かどうかを確かめる
python analyze_usage.py                    # 実際に使ったときに、差し込んだ記憶が使われたかを調べる
```

過去のセッションを時刻順に体験させながら、「その時点で思い出したものに、Claude が実際にあとで使った語が入っていたか」を測る。
RAG・キーワード検索・直近と比べ、仕組みを1つずつ外して効き目を確かめている。

## ファイル

| ファイル | 中身 |
|---|---|
| `brain.py` | 記憶のしくみ(皮質・海馬・睡眠・想起・強化・展望記憶) |
| `import_sessions.py` | セッション記録を読み、時刻どおりに体験させる |
| `store.py` | やり取りの全文と、部分ごとの意味・キーワード検索 |
| `embed.py` | Ollama での埋め込み |
| `intentions.py` | 「これからやること」の取り出し |
| `hook.py` / `server.py` | Claude Code のフックと常駐サーバー(画面もここから) |
| `memory_detail.py` | 鍵から記録を開く |

記憶のデータ(`brain_state.json`・`records.sqlite`・埋め込み)と使ったときの記録(`logs/`)は、
個人の会話を含むので、リポジトリには入れない。
